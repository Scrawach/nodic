# Результаты прототипа совместного редактирования

Дата: 2026-09-13. Связано со [спецификацией #1](https://github.com/Scrawach/nodic/issues/1).

## Вопрос

Подходит ли сочетание Yjs для текста и последовательно проверяемых команд для графа, чтобы сохранять конкурентные правки, персональную отмену и ограничения связей?

## Наблюдения

Пройден интерактивный HTML-стенд в Microsoft Edge через Playwright. Это выполнение сценариев прототипа, а не тестовый набор приложения. Два независимых Y.Doc и серверный Y.Doc использовали настоящую библиотеку Yjs 13.6.32; граф и доставка моделировались в одном процессе страницы.

| Сценарий | Наблюдаемый результат |
| --- | --- |
| Два автора дописывают один текст до обмена | После доставки в обратном порядке и с повторами обе копии сохранили оба добавления |
| Персональная отмена и повтор текста | Отмена Ани убрала только её добавление; текст Бориса сохранился; повтор вернул добавление Ани |
| Удаление ноды при тексте в пути | Реплика исчезла, позднее обновление сохранилось в скрытом тексте; отмена вернула ноду, текст Бориса и исходную связь |
| Конкурентная обычная связь и вариант | Первая связь принята, несовместимая вторая отклонена; две связи в варианты приняты |
| Отмена после чужого перемещения | Позиция Бориса сохранилась, отмена Ани пропущена с объяснением |
| Временное отключение автора | Ввод отключён, ожидающее изменение удержано; после подключения оба текста сошлись |

Ошибок выполнения JavaScript при прохождении сценариев не наблюдалось. Внешних ресурсов для запуска итогового HTML не требуется; библиотека включена внутрь файла. Вёрстка проверена по снимку страницы.

## Вывод

Выбранная модель подходит для первого рабочего среза. Окончательное доказательство сохранности требует настоящего сервера и БД. Макет доски этим прототипом не выбирался.

Не проверены: настоящие соединения между компьютерами, запись на диск, сбои процесса, права доступа, курсоры текста/IME, составная история отмены, повтор удаления и 1 000 нод с 10 авторами. Простой textarea стенда не следует переносить в рабочий совместный редактор; использовать готовый binding CodeMirror.

## Воспроизведение

Исходники, автономный `collaboration.html` и пошаговые наблюдения сохранены в [ветке prototype/collaboration-model](https://github.com/Scrawach/nodic/tree/prototype/collaboration-model/prototypes/collaboration), коммит `baf9435e2282b7e2ab6f503c9f60b6c129743812`. Открыть HTML двойным кликом, выбрать сценарий и нажимать шаги слева направо. Свободные действия доступны над сценариями; смена сценария сбрасывает стенд.

Данные только в памяти. `assemble.py` повторно собирает HTML из приложенной версии библиотеки и исходников без установки пакетов; для открытия уже собранного файла Python не нужен.
