# 19. Совместное редактирование текста внутри ноды

Статус: не начата, активная очередь UI/UX. Triage: ready-for-agent. GitHub Issue: не опубликована. Зависимости: 16–18.

## Задача

Двойной клик непосредственно по тексту реплики или варианта включает редактирование внутри этой ноды, по принципу Figma. Дополнительное модальное окно для текста не открывается. Это явное изменение прежнего требования о модальном редакторе; соответствующие документы нужно обновить после реализации.

## Критерии готовности

- Внутри ноды доступен полный многострочный текст, не только превью. Длинный текст можно прочитать и отредактировать; способ размещения/прокрутки не уменьшает шрифт и не перекрывает соседние элементы без контроля.
- Клик вне редактора или Escape завершает локальное редактирование; Enter вводит новую строку. Завершение не отменяет введённое и не служит отдельной командой сохранения. Фокус клавиатуры предсказуем.
- Выделение текста и движение каретки не перемещают ноду и не запускают рамку выделения доски; сокеты и обычное движение ноды вне текста продолжают работать. Согласовать со средней кнопкой из 15.
- Сохраняются Yjs/CodeMirror, одновременный ввод двух авторов в одну ноду, курсоры/выделения коллег и общая персональная Undo/Redo из 18. Не заменять совместный текст отправкой строки целиком.
- Сохранение подтверждается только после COMMIT БД; очередь IndexedDB, повторы после reconnect, офлайн-блокировка и сохранность после перезагрузки не ухудшаются.
- Удаление редактируемой ноды коллегой завершает редактор с уведомлением, не воскрешает ноду и сохраняет прежние гарантии текста/отмены. Поздние ответы не возвращают закрытый редактор.
- Выбор/смена персонажа реплики остаются доступны без старого текстового модального окна (например, через имя персонажа в ноде). Для варианта персонаж не появляется. Справочник и управление персонажами сохраняются.

## Проверки

Независимые браузерные контексты: конкурентный ввод, разные ноды, длинный многострочный текст, выделение текста против рамки/drag, общий порядок Undo/Redo, удаление коллегой, offline/reconnect, потеря ACK и повторное открытие. Визуально проверить масштаб, фокус, переполнение и соответствие Midline. Полный набор AGENTS.md; переписать прежние модальные сценарии под реальную работу внутри ноды. Обновить спецификацию (история 16 и решение о редакторе), README, first-slice, матрицу v1 и PROGRESS; отдельный коммит.
