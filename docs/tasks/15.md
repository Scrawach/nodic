# 15. Навигация средней кнопкой и выделение левой

Статус: не начата, активная очередь UI/UX. Triage: ready-for-agent. GitHub Issue: не опубликована. Зависимость: 14.

## Задача и критерии готовности

- Убрать курсор руки/grab/grabbing на доске и нодах. Для обычной работы использовать стрелку; текстовый курсор допустим непосредственно при редактировании текста.
- Панорамирование доски выполняется удержанием средней кнопки мыши, без браузерного автоскролла. ЛКМ на пустой доске начинает рамку выделения нескольких нод, а не панорамирование.
- ЛКМ на ноде выбирает её; перетаскивание выбранной ноды перемещает выбранную группу как прежде. Сокеты сохраняют создание связей, ПКМ — контекстные меню. Масштабирование и миникарта остаются работоспособны.
- Выделение рамкой и движение группы согласованы с присутствием коллег; выделение не создаёт сохранённую операцию. Движение группы остаётся атомарным и отменяется одним шагом.
- Обновить подсказки управления. При вводе текста и работе с формами жесты доски не перехватываются; учесть последующую задачу 19.

## Проверки

Публичные браузерные жесты: средняя кнопка двигает камеру без изменения графа; ЛКМ выделяет рамкой без сдвига камеры; перемещение группы, создание связи, ПКМ, масштаб, миникарта. Проверить курсоры и двух независимых авторов, повторное открытие сохранённых позиций. Полный набор AGENTS.md, обновление PROGRESS и отдельный коммит.

Точки входа: src/client/App.tsx, style.css, session.ts, tests/browser/collaboration.spec.ts. Оптимизация 12/13 исключена.
