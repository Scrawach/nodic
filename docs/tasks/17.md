# 17. Слабая светлая сетка и привязка по сокету

Статус: завершена и проверена 2026-09-16. GitHub Issue: не опубликована. Зависимость: 16 (окончательная геометрия сокетов).

## Задача и критерии готовности

- Фон доски — едва видимая светлая сетка поверх тёмной темы. Сетка не конкурирует с текстом, связями и выделением; её шаг совпадает с шагом привязки в координатах доски при любом масштабе и панорамировании.
- Привязка включена по умолчанию, предусмотрен доступный переключатель. Конкретный шаг выбрать при реализации и записать в документации.
- Якорь привязки — центр первого левого сокета, а не левый верхний угол ноды. Для ноды без левого сокета использовать центр первого доступного сокета и явно описать это правило.
- Создание, вставка и завершение перемещения согласованы с сеткой. Группа сдвигается одной общей дельтой по якорю ведущей ноды, сохраняя взаимные позиции, связи и форму группы; не округлять каждую ноду независимо.
- Сохраняется окончательная позиция после привязки. Два автора видят одинаковые координаты; Undo/Redo восстанавливает точные позиции. Старые проекты не перекладываются автоматически при открытии или включении привязки.

## Проверки

Проверить реальные жесты на нескольких масштабах, начало/реплику/вариант/конец, группу, создание/вставку, отключение привязки, Undo/Redo, двух авторов и перезагрузку. Утверждения через публичные операции и браузер, без чтения таблиц БД. Полный набор AGENTS.md, PROGRESS и отдельный коммит.

Точки входа: src/client/App.tsx, style.css, clipboard.ts; геометрия сокетов после 16. Оптимизация 12/13 исключена.

## Реализация

Шаг 24 координаты доски; слабые светлые линии синхронизированы с масштабом и панорамированием. Привязка включена при открытии доски, доступный переключатель в шапке имеет aria-pressed. Якорь берётся из измеренного handleBounds: первый левый сокет, иначе первый доступный (выход начала). Для новых и вставляемых нод та же StoryNode измеряется в отдельной невидимой ReactFlow-сцене до отправки единственной команды; образец не участвует в доске, миникарте, fitView, выделении или присутствии. Превью и персонаж совпадают с итоговым отображением.

Группа перемещается общей дельтой ведущей ноды; при вставке ведущая — первая нода фрагмента, точки изгиба связей смещаются вместе с нодами. При выделении толщина границы постоянна, поэтому снятие выделения не смещает сокет. Загрузка, включение сетки и изменение текста не перекладывают ноды. Автоматическая серверная нода начала получает привязку при первом пользовательском drag; её создание не зависит от CSS клиента.

Проверки: typecheck, npm test 22/22, полный npm run test:e2e 25/25 Microsoft Edge, build и git diff --check прошли. Два новых браузерных сценария покрывают сокеты всех типов, масштабы, создание/вставку, динамическую высоту реплик, группу, отключение привязки, Undo/Redo, двух авторов и reload.
