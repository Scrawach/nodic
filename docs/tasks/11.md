# 11. Подготовка публичного запуска

Статус и текущий шаг: [PROGRESS.md](PROGRESS.md). GitHub Issue: ещё не опубликована.

## Задача

Проработать лимиты запросов, срок и отзыв сессий, наблюдаемость, резервное копирование и восстановление.

## Зависимости

10; отдельный этап.

## Критерии готовности

Перед публикацией определить среду и эксплуатационные требования; проверить восстановление резервной копии и отсутствие секретов в логах. Публикация не входит в эту карточку.

## Точки входа

src/server; compose.yaml; docs. Перед изменением читать актуальный код и применимые AGENTS.md.

## Проверки

Проверка ограничений, сессий и восстановления в выбранной среде. Для изменений совместной работы обязательны все проверки из корневого AGENTS.md.
