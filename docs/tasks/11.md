# 11. Работа с персонажами в проекте

Статус и текущий шаг: [PROGRESS.md](PROGRESS.md). GitHub Issue: ещё не опубликована.

## Задача

Отображать персонажей в боковой панели проекта отдельным списком над диалогами. Использовать такое же оформление списка и похожую кнопку добавления, как у диалогов. Подключить существующие операции создания, переименования, изменения цвета и удаления персонажей. У каждого персонажа помимо имени должен отображаться их цвет рядом, чтобы было сразу отличимо.

## Зависимости

05, 06.

## Критерии готовности

- Список персонажей текущего проекта расположен над списком диалогов и оформлен аналогично ему.
- Кнопка добавления персонажа расположена и оформлена по аналогии с кнопкой добавления диалога.
- Выбор персонажа открывает его редактирование; доступны имя, цвет и удаление с подтверждением.
- Создание, изменение и удаление отражаются в списке; сохраняются существующие права доступа и обновления у других авторов.

## Точки входа

src/client/App.tsx; src/client/Characters.tsx; src/client/style.css. Перед изменением читать актуальный код и применимые AGENTS.md.

## Проверки

Проверить расположение и оформление списка над диалогами, пустой список, добавление, выбор, редактирование и удаление персонажа. Проверить обновления у двух независимых авторов и изоляцию проектов. Для изменений совместной работы обязательны все проверки из корневого AGENTS.md.
