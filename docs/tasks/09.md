# 09. Нагрузка 1 000 нод и 10 авторов

Статус и текущий шаг: [PROGRESS.md](PROGRESS.md). GitHub Issue: ещё не опубликована.

## Задача

Создать воспроизводимый профиль нагрузки и измерить загрузку доски, ACK, доставку, перемещение и память.

## Зависимости

8.

## Критерии готовности

Отчёт содержит окружение, методику, p50/p95, результаты и выбранные пороги. Выявленные проблемы исправлены или описаны отдельными задачами.

## Точки входа

tests; scripts; docs. Перед изменением читать актуальный код и применимые AGENTS.md.

## Проверки

Реальные соединения и браузерная доска; повторяемый запуск. Для изменений совместной работы обязательны все проверки из корневого AGENTS.md.

## Результат — 2026-09-15

Измерение завершено: `npm run profile:load`, [методика, два запуска и исходные выборки](../research/load-profile.md). Десять независимых браузерных контекстов, 1000 нод/998 связей, реальные ACK/доставка текста и движения, pointer gestures, кадры и heap.

Загрузка проходит выбранный бюджет, задержки редактирования, кадры и heap — нет. Статус производительности 1000/10: **blocked**, готовность v1 под нагрузкой не подтверждена. Отдельные задачи P1: [12](12.md) и [13](13.md). Их реализация не входит в измерение 09; публикация GitHub требует одобрения после отказа автоматической проверки разрешений.
