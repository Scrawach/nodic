# 03. Единая история текста и структуры

Статус и текущий шаг: [PROGRESS.md](PROGRESS.md). GitHub Issue: ещё не опубликована.

## Задача

Объединить порядок действий текущей вкладки между разными редакторами и доской.

## Зависимости

02.

## Критерии готовности

Ctrl+Z/Redo следуют порядку действий, сохраняют чужие правки и корректно группируют ввод. История живёт в текущей сессии вкладки; смена фокуса не меняет смысл отмены.

## Точки входа

src/client/session.ts; src/client/TextEditor.tsx; src/client/App.tsx. Перед изменением читать актуальный код и применимые AGENTS.md.

## Проверки

Два независимых браузера: текст → перемещение → другой текст → последовательные Undo/Redo; конфликт обратной команды. Для изменений совместной работы обязательны все проверки из корневого AGENTS.md.
