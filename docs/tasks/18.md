# 18. Отмена и повтор только через шорткаты

Статус: не начата, активная очередь UI/UX. Triage: ready-for-agent. GitHub Issue: не опубликована. Зависимость: 17.

## Задача и критерии готовности

- Убрать видимые кнопки Undo/Redo («Отменить»/«Повторить», названные пользователем «назад»/«вернуть») с доски. Это не удаление навигации назад, закрытия окна или отмены подтверждения удаления.
- Сохранить общую историю текста и структуры: Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z и Ctrl/Cmd+Y. Указать сочетания в подсказках без новых кнопок Undo/Redo.
- Смена фокуса не меняет порядок отмены, чужие правки не отменяются. Обычные поля форм сохраняют нативную отмену; текстовый редактор диалога использует общую историю. Ограничения при ожидающей операции и офлайне сохраняются.
- Обновить существующие e2e: пользовательские сценарии отмены должны работать через клавиатуру, а не удалённые кнопки. Расширение истории на управление проектом/справочником не входит в эту задачу.

## Проверки

Клавиатурные сценарии текст → движение → другой текст, Undo/Redo, пустая история, конфликт чужой правки, потеря подтверждения; отсутствие кнопок в UI. Полный набор AGENTS.md, актуализация README/first-slice/матрицы, PROGRESS и отдельный коммит.

Точки входа: src/client/App.tsx, TextEditor.tsx, session.ts, tests/browser. Оптимизация 12/13 исключена.
