# 01. Надёжное создание объектов

Статус и текущий шаг: [PROGRESS.md](PROGRESS.md). GitHub Issue: ещё не опубликована.

## Задача

Создание ноды, диалога и персонажа по HTTP сейчас не дедуплицируется. Ввести устойчивый идентификатор операции, транзакционное сохранение результата и повторную доставку клиента.

## Зависимости

Нет.

## Критерии готовности

Один идентификатор и одинаковое тело возвращают тот же объект после конкурентного повтора и перезапуска. Иное тело с тем же ключом отклоняется. Проверка доступа выполняется при каждом повторе. Узел и результат операции фиксируются вместе; рассылка только после COMMIT. Клиент повторяет неопределённый сетевой исход с прежним ключом, включая восстановление после перезагрузки.

## Точки входа

src/server/app.ts; src/server/live.ts; src/client/api.ts; src/server/migrations. Перед изменением читать актуальный код и применимые AGENTS.md.

## Проверки

Публичные API: повторы, конкуренция, смена тела, изоляция проектов, перезапуск. Браузер: потеря ответа, перезагрузка и отсутствие дублей. Для изменений совместной работы обязательны все проверки из корневого AGENTS.md.
