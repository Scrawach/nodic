# 08. Отказы и восстановление

Статус и текущий шаг: [PROGRESS.md](PROGRESS.md). GitHub Issue: ещё не опубликована.

## Задача

Проверить потерю ACK, перезапуск процесса, недоступность PostgreSQL и закрытие вкладки во время сохранения очереди.

## Зависимости

01–07.

## Критерии готовности

Не показывать Сохранено до COMMIT. После восстановления принятые операции доступны, повторы не создают дублей. Явно документировать границу гарантии до завершения IndexedDB.

## Точки входа

tests/app.test.ts; tests/browser/collaboration.spec.ts; src/client/session.ts. Перед изменением читать актуальный код и применимые AGENTS.md.

## Проверки

Публичные операции и независимые контексты; управляемые отказы без SQL-утверждений о таблицах. Для изменений совместной работы обязательны все проверки из корневого AGENTS.md.

## Результат

Добавлены tests/recovery.test.ts (настоящий PostgreSQL за управляемым TCP-прокси и отдельный процесс API) и tests/browser/recovery.spec.ts (независимые браузерные контексты). Проверены COMMIT до ACK/трансляции, разрыв БД до COMMIT, повтор, потеря ACK, SIGKILL API, восстановление текста и дедупликация старого перемещения после более нового. Браузерные сценарии покрывают незавершённую IndexedDB-транзакцию, закрытие/восстановление вкладки с потерянным ACK, офлайн-удаление с очередями текста/HTTP и сохранение очереди при 403/503.

Исправлены ошибки соединения PostgreSQL, завершавшие процесс; добавлены квитанции удаления, доступные только прежним сессиям до их исходного срока истечения. Граница гарантии и исключения записаны в [рабочем срезе](../first-slice.md#гарантия-сохранения-и-восстановления). Результаты полного прогона — в PROGRESS.md.
