# 07. Присутствие авторов на доске

Статус и текущий шаг: [PROGRESS.md](PROGRESS.md). GitHub Issue: ещё не опубликована.

## Задача

Показать список присутствующих авторов, курсоры и выделения на доске; согласовать идентичность с редактором текста.

## Зависимости

Нет.

## Критерии готовности

Присутствие временное, исчезает после отключения, не содержит секретов доступа. Переключение диалогов корректно очищает состояние.

## Точки входа

src/client/App.tsx; src/client/session.ts; src/server/live.ts; src/shared/protocol.ts. Перед изменением читать актуальный код и применимые AGENTS.md.

## Проверки

Два браузера: движение, выделение, смена диалога и отключение. Для изменений совместной работы обязательны все проверки из корневого AGENTS.md.
