## Задача

Отдельная страница проекта для создания, переименования, цвета и удаления персонажей.

## Критерии готовности

Переименование видно во всех диалогах. Удаление транзакционно очищает ссылки в репликах, сохраняя текст. Конкурентное назначение удаляемого персонажа безопасно.

## Точки входа

src/client/App.tsx; src/server/app.ts; src/server/graph.ts. Перед изменением читать актуальный код и применимые AGENTS.md.

## Проверки

Два автора в разных диалогах: переименование, удаление, конкурентное назначение, изоляция проектов. Для изменений совместной работы обязательны все проверки из корневого AGENTS.md.
