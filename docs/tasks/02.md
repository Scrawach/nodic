Добавить обратные команды для создания, перемещения, связей, назначения персонажа и удаления нод.

## Критерии готовности

Отмена сохраняет чужие последующие изменения; удаление восстанавливает текст и допустимые связи. Групповое перемещение — один шаг. Конфликты объясняются пользователю. Повторы идемпотентны.

## Точки входа

src/server/graph.ts; src/server/live.ts; src/shared/protocol.ts. Перед изменением читать актуальный код и применимые AGENTS.md.

## Проверки

Два автора: чужое перемещение, удалённый конец связи, поздний текст, повтор Undo/Redo и атомарная группа. Для изменений совместной работы обязательны все проверки из корневого AGENTS.md.
