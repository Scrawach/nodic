# 16. Пропорции нод и читаемость содержимого

Статус: выполнена 2026-09-16. GitHub Issue: не опубликована. Зависимости: 14, 15 выполнены.

## Задача

Сделать ноды компактнее и содержательнее: сейчас внешний размер велик относительно текста. [Второй скриншот пользователя](references/node-proportions.png) — пример относительных пропорций, не точная копия Figma. Его яркие заливки и оформление не переносить: стиль задаёт 14.

## Критерии готовности

- В реплике имя персонажа и текст заметно крупнее относительно контейнера; меньше пустого пространства и декоративных элементов. Не уменьшать шрифт ради длинного текста, сохранять перенос и читаемую иерархию имени/реплики.
- Скорректировать отношение ширины/высоты треугольника варианта, чтобы текст занимал полезную площадь и не обрезался наклонными краями. Вариант остаётся визуально отличим от реплики.
- Начало и конец согласованы со стилем; направление связей, сокеты, hit-area, выделение и метки коллег остаются понятными. Пропорции не копируются пиксель в пиксель из референса.
- Проверены пустой, короткий, многострочный и длинный русский текст, длинное имя, неизвестный/отсутствующий персонаж, разные масштабы. Поведение переполнения явно описано; геометрия предусматривает редактор внутри ноды из 19.
- Изменение формы и сокетов не портит существующие сохранённые связи, изгибы или позиции.

## Проверки

Визуальное сравнение до/после на одинаковом масштабе, реальные соединение/выделение/перетаскивание и повторное открытие. Полный набор AGENTS.md, PROGRESS и отдельный коммит.

Точки входа: src/client/App.tsx, StoryEdge.tsx, style.css, shared/model.ts. Оптимизация 12/13 исключена.

## Реализация и границы

- Реплика шириной 240px: имя персонажа и текст 16px вместо 12px, имя полужирное и переносится полностью. Служебная строка «≋ Реплика» и разделитель убраны. Пустая/короткая реплика ниже прежней; длинная растёт по содержимому до шести строк превью. Поля 12px, без уменьшения шрифта.
- Вариант — резкий треугольник 240×205px вместо 270×180px: отношение сторон ближе к референсу, площадь контейнера практически прежняя. Текст 16px, четыре строки, расположен в безопасном прямоугольнике x=64, y=108, width=112, max-height=89.6. Скосы не обрезают буквы. Пустой вариант показывает приглашение к вводу.
- Превью по-прежнему содержит до 240 символов серверного текста. CSS ограничивает реплику шестью строками, вариант четырьмя, с многоточием при переполнении строк. Это обзор доски, не ограничение полного текста: сегодня полный текст доступен по двойному клику в редакторе; задача 19 должна раскрывать его внутри ноды. Имя персонажа не обрезается, длинные слова переносятся.
- Сохранённые координаты, идентификаторы сокетов и форма связей не менялись; миграций нет. ReactFlow заново измеряет размер реплики при смене имени/превью. Начало/конец сохранены компактными. Сокеты имеют hit-area 20×20px.
- Для задачи 17: у варианта вход (60,102.5), выход (180,102.5) относительно верхнего левого угла — середины наклонных рёбер. У реплики вход/выход на боковых гранях при 50% фактической высоты; высота зависит от текста/имени. Использовать измеренную геометрию ReactFlow, учитывать текущую толщину границы выделения, не сохранять старые размеры в данные. Для 19: область превью варианта ограничена формой, полному редактору потребуется раскрытие области без потери переносов и доступности сокетов.
