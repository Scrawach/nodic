# Гайд по дизайну Midline'85

## Визуальная идея

Тёмный экран старого терминала: холодный почти чёрный фон, выцветший белый текст, квадратные панели и дискретный узор. Источник атмосферы — предоставленный пользователем игровой кадр с CRT и дизерингом. Не копировать из кадра персонажей, диалоги, часы или интерфейс ОС на каждую страницу; повторять визуальный язык.

## Палитра

| Назначение | Значение |
| --- | --- |
| Фон страницы | `#0b0b0d` |
| Панель | `#141416` |
| Экран плеера | `#101013` |
| Основной текст | `#d6d5cf` |
| Вторичный текст | `#9b9b9c` |
| Разделитель | `#343437` |
| Граница контрола | `#555558` |
| Граница экрана | `#515154` |
| Нейтральный акцент | `#c4bdb2` |
| Редкий красный акцент | `#a64a48` |

Красный применяется к небольшому знаку или детали, а не заливает страницу. Яркая основная кнопка — светлый фон и тёмный текст. Не использовать прежний лаймовый цвет, неоновые градиенты и зелёную терминальную тему.

## Типографика

`font-family: "Courier New", monospace`. Основной текст 16px, line-height 1.5–1.6. Контролы 14px, подписи 12–13px. Для длинного текста не уменьшать размер ради вмещения; переносить строки. Заголовок игры: `clamp(32px,4.5vw,56px)`, вес 700, line-height 1.1, letter-spacing -2px (на мобильном -1px). Метки: 12px с разрядкой 2px. Огромный Scrawach на главной и крупный код 404 — отдельные композиционные акценты, а не стандарт для всех заголовков.

Короткие функциональные тексты: «Играть», «Скачать игру», «Страница не найдена», «Последнее обновление». Никаких «Больших приключений», «Сделано с душой» и подобных лозунгов. Не выдумывать название игры, дату обновления или доступность сборок.

## Сетка и геометрия

Контент до 1180px, по центру. Внешние поля 30px, ниже 700px — 18px. Шапка около 82px с нижним разделителем 1px. Заголовочная область: 42px сверху, 36px снизу; мобильная — 30px. Секции отделяются пространством и тонкими линиями.

У панелей и кнопок радиус 0. Карточки платформ образуют общую таблицу с границами: четыре колонки без промежутка, ниже 700px — две, ниже 360px — одна. Внутренние поля 23px, мобильные 18px. Для других наборов контента количество колонок выбирать по смыслу, сохраняя плотность и границы.

Плеер имеет aspect-ratio 2.3, на мобильном 1.25. Это правило только для игрового экрана. Полноэкранный iframe перекрывает декоративный canvas, чтобы эффекты сайта не накладывались на саму игру.

## Дизеринг и CRT

Игровая обложка использует статический Bayer 4×4:

```text
 0  8  2 10
12  4 14  6
 3 11  1  9
15  7 13  5
```

Реализация: `draw()` в `static/app.js`. Canvas в половине CSS-разрешения, `image-rendering: pixelated`; сравнение яркости с порогом матрицы формирует два тёмных тона RGB (13,13,16) и (44,44,47). Узор перерисовывается при изменении размера, не в бесконечном цикле. Сверху — мягкая виньетка и статические строки развёртки с шагом 4px.

Для простой страницы без JS достаточно CSS-точек с шагом 4px и слабой радиальной маской, как в `static/404.html` и `static/index.html`. Это облегчённая текстура, не алгоритмический дизеринг. Все декоративные слои: pointer-events none, за текстом, без семантики для screen reader. Без мерцания, тряски, сканирующих анимаций и RGB-сдвига букв.

## Компоненты и состояния

Основная кнопка: светлая заливка, тёмный текст, граница 1px, padding около 13px 37px. Вторичная: прозрачная, граница `#555558`, hover `#242426`. На клавиатурном фокусе видимый outline с отступом. Недоступный элемент действительно disabled или без href, а не только серый. SVG-иконки платформ наследуют currentColor; декоративные иконки имеют aria-hidden.

Пустая сборка обозначена текстом; нет ложной даты или активной кнопки скачивания. 404 не рассказывает о secret или существовании закрытого билда. API сохраняет машинно-читаемые ошибки. Публичная главная не содержит кнопок, ссылок или скриптов.

## Как повторить стиль

1. Определить функцию страницы и необходимые состояния.
2. Взять палитру и моноширинную типографику; задать контейнер и адаптивные поля.
3. Выстроить иерархию текстом и разделителями. Добавить только нужные панели и действия.
4. Добавить одну спокойную текстурную область за контентом, если она помогает композиции.
5. Проверить контраст, переносы, клавиатуру и HTTP-поведение. Не затрагивать ключи и настройки доступа ради визуальных изменений.

## Файлы-эталоны

- `static/dev.html`: структура страницы игры.
- `static/style.css` + `static/horror.css`: база и текущая тема (важен порядок).
- `static/app.js`, функция `draw()`: алгоритм дизеринга.
- `static/index.html`: публичная статичная композиция.
- `static/404.html`: нейтральная страница ошибки.

Пути указаны от корня репозитория. Нужные сведения для другого агента находятся в этом гайде; исходный скриншот на компьютере пользователя не требуется.
