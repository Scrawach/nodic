# Стиль Midline'85

Перед изменением страницы прочитай [гайд](README.md): в нём зафиксированы токены и композиция. Сверься с актуальными `static/dev.html`, `static/style.css`, `static/horror.css` и функцией `draw()` в `static/app.js` (пути от корня проекта). CSS темы подключается после базового CSS; зелёные токены базового файла не являются текущим стилем.

Вырази атмосферу через почти чёрный фон, моноширинный текст, резкие границы, статическую зернистость и редкий тускло-красный акцент. Не превращай страницу в декорацию с вымышленными сигналами, диагнозами, таймерами или лозунгами. Эффекты остаются за текстом и элементами управления.

Сохраняй назначение поверхности: главная Scrawach статична и не ссылается на DEV-страницу; Midline'85 содержит игру; 404 показывает нейтральную ошибку и переход на главную. Не переносить игровые контролы на остальные страницы автоматически.

Для новой страницы переиспользуй существующий CSS и добавляй только стили её композиции. В другом проекте перенеси токены из гайда и необходимые компоненты, не копируя весь сайт. Не добавляй фреймворки, шрифтовые сервисы или библиотеки ради оформления.

Проверяй длинный русский текст, узкую ширину 360px, увеличение текста, фокус клавиатуры, пустые и ошибочные состояния. Проверяй затронутое поведение, а не точное совпадение HTML-строк. Для серверной ошибки сохрани настоящий HTTP-статус; не заменяй API JSON на HTML. Перед передачей перечисли изменённые поверхности и выполненные проверки. Не утверждай, что визуальная проверка выполнена, если браузер не проверялся.
