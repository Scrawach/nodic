# Nodic

Совместное создание нарративных диалогов для игр.

## Language

**Проект**: Набор диалогов и общий для них справочник персонажей.
_Avoid_: уровень, доска

**Диалог**: Направленный граф реплик и выборов с одной точкой начала.
_Avoid_: проект, уровень

**Доска**: Визуальное рабочее пространство одного диалога, на котором автор размещает ноды и связи.

**Нода начала**: Единственная точка входа в диалог; входящих связей не имеет.

**Реплика**: Нода с текстом высказывания и необязательным персонажем, который его произносит.
_Avoid_: сообщение

**Вариант**: Отдельная нода с текстом ответа или действия, выбираемого игроком.
_Avoid_: список вариантов, кнопка

**Нода конца**: Необязательное явное завершение ветки без исходящих связей.

**Связь**: Направленный переход между нодами одного диалога.

**Персонаж**: Участник повествования из справочника проекта, на которого могут ссылаться реплики.
_Avoid_: автор, пользователь

**Автор**: Человек, редактирующий нарративный проект.
_Avoid_: персонаж, игрок

**Владелец**: Автор с правом удаления проекта и его диалогов.

**Игрок**: Будущий участник игры, который выбирает варианты при прохождении диалога.
_Avoid_: автор
